# VibeOn — архитектура и стек

## Стек
- **Фронтенд и бэкенд:** Next.js (App Router) + TypeScript, React Server Components, Tailwind CSS (цвета и отступы — из ТЗ).
- **База:** PostgreSQL + Prisma ORM.
- **Файлы:** S3-совместимое хранилище в РФ (например, Timeweb S3) — картинки, аудио, PDF, чеки.
- **Реальное время (урок):** WebSocket (Socket.IO или Liveblocks/Yjs-аналог на своём сервере) — синхронизация ответов, «показать ученику», доска, присутствие.
- **Очереди и фоновые задачи:** Redis + BullMQ — напоминания, выставление счетов по расписанию, обработка ИИ-заданий, распознавание файлов.
- **Развёртывание:** Docker Compose на VPS TimeWeb (Москва), Nginx, HTTPS (Let’s Encrypt), ежедневные бэкапы базы.

## Модель данных (основные сущности)
- **User** (id, email, passwordHash?, name, role: TEACHER|STUDENT, lang, timezone, createdAt)
- **TeacherProfile** (userId, tariff, trialUntil, settings)
- **Student** (id, userId?, teacherId, status: INVITED|ACTIVE|ARCHIVED, form JSON (стартовая анкета), payType: PACK|POSTPAID, price, payerName?, payerContact?, billRule, remindEveryDays)
- **Invite** (id, teacherId, studentId, token, channel: EMAIL|TELEGRAM, expiresAt, usedAt)
- **Course** (id, teacherId, title, level, category, audience, cover, order) → **Unit** (courseId, title, order, outcomes[]) → **LessonTemplate** (unitId, title, order, sections JSON)
- **Section / Task** внутри урока: Task (id, type, title, content (разметка, см. Разметка_заданий.md), options JSON, hidden, order)
- **LessonInstance** (id, templateId, studentId|groupId, startsAt, durationMin, status: PLANNED|DONE|CANCELLED|MISSED, note, recurrence)
- **Answer** (lessonInstanceId, taskId, studentId, payload JSON, attempts, status, aiDraft, teacherReview, shownToStudent)
- **Homework** (lessonInstanceId, taskIds[], dueAt, status, teacherComment)
- **Word** (studentId, word, translation, definition, example, ownExample, level 0–4, source lessonId)
- **Roadmap** (studentId, type, goal, deadline?, showDate, pace, stages JSON, approvedAt) + **Checkpoint** (results по навыкам)
- **Pack** (studentId, lessonsTotal, lessonsLeft, price, startsAt, frozenUntil?) · **Invoice** (studentId, amount, period, status: SENT|PROOF_SENT|PAID|CANCELLED, proof: screenshot|text, aiRead JSON, autoAccepted, receiptFile)
- **Message** (chat учитель–ученик), **Question** (по заданию, AI-ответ, ответ учителя), **Notification** (лента «Что нового», done/read)
- **Feedback** (teacher → student, периодический), **Note** (заметки учителя и ученика)

## Вход и безопасность
- Почта + пароль (bcrypt/argon2), подтверждение почты ссылкой, вход по одноразовой ссылке (magic link), OAuth Яндекс ID и VK ID.
- Сессии — httpOnly cookie; «Запомнить меня» — долгая сессия.
- Права: учитель видит только своих учеников; ученик — только свои данные и уроки.
- Гостевая ссылка на урок (Поделиться) — токен только на чтение/выполнение, без сохранения в кабинет; отключается учителем.

## ИИ
- **ИИ-шлюз на сервере**: все функции обращаются к нему; ключи API только на сервере; учитель ничего не подключает, расходы входят в тариф; лимиты по тарифу.
- **Задачи и модели:** быстрая модель — «Помочь с ИИ», переводы и примеры слов, распознавание файлов и фото, «Мне непонятно»; сильная модель — проверка эссе и альтернативных ответов, черновик маршрута, фидбэк. Учитель подтверждает результаты ИИ перед показом ученику, где это предусмотрено.
- **Речь:** распознавание речи (STT) и синтез голоса (TTS) отдельными сервисами через шлюз (например, Yandex SpeechKit или аналог).
- **Картинки:** поиск по бесплатным фотобанкам и/или отдельный сервис генерации (не Claude).
- **Экономия:** кэшировать общие результаты (слова урока, распознанный учебник); простые проверки (точное совпадение, орфография) — кодом без ИИ.
- **Россия:** API Anthropic официально недоступен из РФ — нужен промежуточный сервер в поддерживаемой стране или российские модели (YandexGPT, GigaChat) для части функций; шлюз позволяет комбинировать. Перепроверить перед запуском.

## Оплаты
- **Ученик → учитель:** платформа не принимает деньги; ученик платит учителю напрямую и присылает скриншот/текст; ИИ читает сумму и дату; при совпадении — автоприём; чек учителя («Мой налог») прикрепляется к оплате.
- **Учитель → платформа (подписка):** российский платёжный шлюз (ЮKassa, CloudPayments или аналог), рекуррентные платежи.

## Уведомления
Telegram-бот (напоминания о словах, уроках, счетах, ответах), почта (подтверждение, вход по ссылке, счета). Время напоминаний — из настроек пользователя.

## Видеосвязь
Вариант 1 (быстрее): внешняя ссылка учителя (Zoom/Яндекс Телемост/Google Meet) — кнопка «Присоединиться к звонку». Вариант 2: встроенный звонок (WebRTC через сервис вроде LiveKit на своём сервере).

## Юридические требования (РФ)
Уведомление Роскомнадзора об обработке ПД; политика конфиденциальности и условия использования; хранение ПД граждан РФ в РФ (152-ФЗ, ст. 18 ч. 5); согласие на трансграничную передачу, если тексты уходят в зарубежный ИИ; в ИИ отправлять только содержание заданий/ответов без имени и контактов. Проверить с юристом.

## Переводы интерфейса
Все строки — через i18n (ключи RU/EN); в прототипах встречаются непереведённые английские фразы — при разработке перевести полностью.
