# ИИ в конструкторе: картинки к словам и озвучка аудирования

## Картинки для «Слово к картинке»

- В редакторе задания — кнопка **«Сгенерировать картинки (N)»**: ИИ рисует только для слов без картинки.
- **Библиотека.** Каждая картинка сохраняется (таблица `AiImage`: слово, стиль, модель, ссылка). Если слово уже рисовали в том же стиле, картинка берётся из библиотеки — мгновенно и без затрат; у слова появляется пометка «из библиотеки».
- **«Другой вариант»** рисует заново; прежняя картинка остаётся в библиотеке.
- «Выбрать» — своя картинка вместо сгенерированной.

### Как это подключено
- Модель: `AI_MODEL_IMAGE` (по умолчанию `aliceai-image-art-3.0/latest`), синхронный метод `POST https://llm.api.cloud.yandex.net/v1/images/generations`, ~3 с на картинку.
- Подсказка для модели — `prompts/image.md` (`{word}` заменяется словом).
- Стиль — `AI_IMAGE_STYLE` (по умолчанию `flat`). Это ключ библиотеки: если сменить стиль (и подсказку), слова нарисуются заново, старые картинки не смешаются с новыми.
- Код: `src/lib/ai/media.ts` (`pictureFor`), интерфейс — `src/components/builder/AiMedia.tsx`.

## Озвучка скрипта аудирования

- В задании «Аудио» под полем «Скрипт» — **«Озвучить скрипт»**. Готовая запись сразу подставляется как аудио задания; её можно прослушать в редакторе.
- **Диалог:** каждая реплика с новой строки в формате `Имя: реплика`. Собеседники звучат разным тоном (один голос, сдвиг высоты), строки без имени продолжают текущую реплику.
- **Темп:** ×0,8 … ×1,1. **Пауза** между репликами: 0,3 / 0,6 / 1,0 / 1,5 с (добавляется к естественной паузе в конце фразы).
- Лимит — 8000 знаков на задание.

### Как это подключено
- SpeechKit v3: `POST https://tts.api.cloud.yandex.net/tts/v3/utteranceSynthesis`, голос `TTS_EN_VOICE` (по умолчанию `john` — единственный английский голос Яндекса), mp3.
- Каждая реплика синтезируется отдельно; паузы вставляются при склейке кадрами тишины mp3 (разметку `sil<[…]>` SpeechKit обрезает).
- Код: `src/lib/ai/media.ts` (`voiceScript`), разбор скрипта и склейка — `src/lib/ai/tts-script.ts`.
- Позже можно подключить другой голос (внешний провайдер): меняется только функция синтеза в `providers.ts`.

## Проверка на сервере
Выкладка → `aidemo` с параметром `media`: озвучивает тестовый диалог и рисует две картинки; файлы публикуются в ветку `ai-probe-out`.
