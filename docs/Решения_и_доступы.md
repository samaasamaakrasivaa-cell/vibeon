# VibeOn — решения и доступы для запуска

**Главное:** для **разработки** почти ничего из этого не нужно. Claude Code собирает и проверяет платформу на компьютере (localhost) с заглушками: письма — в локальный почтовый ящик Mailpit, ИИ — в тестовый режим, оплата — в тестовый режим. Реальные домен, ключи и сервер нужны только на этапе 11 («Запуск»). Поэтому разработку можно начинать сразу, а пункты ниже заполнять параллельно.

Все значения потом вписываются в файл `.env` (шаблон — `.env.example`). В чат и в код ключи не вставлять.

---

## 1. Домен — решение: купить .ru
- Что сделать: выбрать имя (например, vibeon.ru, vibeon-english.ru), проверить и купить на REG.RU или в TimeWeb.
- Нужно для: HTTPS, писем с адреса домена, входа через Яндекс/VK, поиска.
- Для разработки: не нужен (localhost).
- Вписать: `APP_DOMAIN=`

## 2. Сервер — решение: VPS TimeWeb, Москва
- Рекомендуемая конфигурация на старт: Ubuntu 24.04, 4 vCPU, 8 ГБ RAM, 80–100 ГБ NVMe, ежедневные бэкапы. Позже можно увеличить без переезда.
- Вписать: `SERVER_IP=` (адрес из панели TimeWeb). Пароль/SSH-ключ — только у себя, Claude Code спросит их локально при выкладке.

## 3. Почта для писем — решение: российский сервис рассылки
- Варианты: Unisender Go, SendPulse (транзакционные письма), либо почта на домене в Яндекс 360 (SMTP) для небольших объёмов.
- Нужно: подтвердить домен в сервисе (DNS-записи SPF, DKIM — сервис даст их сам), получить SMTP-логин или API-ключ.
- Для разработки: Mailpit (локальный ящик, письма не уходят наружу).
- Вписать: `SMTP_HOST= SMTP_PORT= SMTP_USER= SMTP_PASS= MAIL_FROM=`

## 4. ИИ — рекомендуемое решение: начать с российского провайдера
- Рекомендация на старт: **Yandex Cloud** — YandexGPT для текста (помощь в конструкторе, проверка, «Мне непонятно», маршрут) и **SpeechKit** для речи (расшифровка записей, озвучка ИИ-собеседника). Один провайдер, данные в РФ, проще с 152-ФЗ.
- Альтернатива: GigaChat (Сбер).
- Claude/другие зарубежные модели: только через ИИ-шлюз и промежуточный сервер в поддерживаемой стране, с согласием пользователей на трансграничную передачу. Решение — после проверки с юристом; архитектура (ИИ-шлюз) это уже позволяет подключить позже без переделки.
- Для разработки: режим `AI_PROVIDER=mock` (ответы-заглушки), затем ключ Yandex Cloud.
- Вписать: `AI_PROVIDER=yandex YANDEX_CLOUD_FOLDER_ID= YANDEX_CLOUD_API_KEY=`

## 5. Ключи сервисов (получаются после покупки домена)
| Сервис | Где получить | Что вписать |
|---|---|---|
| Вход через Яндекс ID | oauth.yandex.ru → создать приложение, адрес возврата `https://ДОМЕН/api/auth/callback/yandex` | `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` |
| Вход через VK ID | id.vk.com → кабинет разработчика → приложение, адрес возврата `https://ДОМЕН/api/auth/callback/vk` | `VK_CLIENT_ID`, `VK_CLIENT_SECRET` |
| Telegram-бот | @BotFather в Telegram → /newbot | `TELEGRAM_BOT_TOKEN` |
| Хранилище файлов (S3) | TimeWeb S3 или Yandex Object Storage → бакет + ключ доступа | `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` |
| Оплата подписки учителей | ЮKassa (подходит ИП и самозанятым) или CloudPayments → магазин, тестовый режим | `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` |

Вход через Яндекс/VK и Telegram — не обязательны для первого запуска: можно стартовать с входа по почте и паролю/ссылке и добавить их позже.

## 6. Решения по продукту (раздел 6 ТЗ) — рекомендации
- **Видеозвонок — решение для первой версии: внешняя ссылка.** Учитель один раз вставляет свою ссылку (Яндекс Телемост, Zoom, Google Meet) в профиль или к уроку, кнопка «Присоединиться к звонку» открывает её. Встроенный звонок (LiveKit) — во второй версии.
- **Тарифы — шаблон, цены вписать самостоятельно:**
  - пробный период: 14 дней, все функции, без карты;
  - «Старт» — до 10 учеников, без ИИ-проверки эссе и ИИ-собеседника: `[ЦЕНА] ₽/мес`;
  - «Профи» — без ограничения учеников, все функции ИИ (с месячным лимитом ИИ-запросов): `[ЦЕНА] ₽/мес`;
  - ученики пользуются бесплатно, платит учитель.
- **Названия:** «Слова» в меню кабинета, «Слова урока» внутри урока; «Домашка» во вкладках, «Домашнее задание» в заголовках.
- **Юридическое (до приёма реальных данных):** политика конфиденциальности, условия использования, согласие на обработку ПД, уведомление Роскомнадзора. Оператор ПД — вы (ИП/самозанятая) — указать реквизиты.

## 7. Что сказать Claude Code
> Доступов к домену, серверу, почте и сервисам пока нет. Разрабатывай всё локально по этапам 1–10 плана с заглушками: Mailpit для писем, AI_PROVIDER=mock, тестовый режим оплаты, локальное хранилище файлов вместо S3. Все настройки бери из .env (шаблон .env.example). Видеозвонок — внешняя ссылка учителя. Вход через Яндекс/VK и Telegram сделай так, чтобы они включались, когда в .env появятся ключи. Выкладку на сервер (этап 11) делаем, когда я дам домен и доступ.
