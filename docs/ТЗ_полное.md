# VibeOn — техническое задание (состояние на 01.11.2026)

Все экраны есть в прототипах (папка 1_прототипы) и на скриншотах (3_скриншоты). Здесь — что должно работать и по каким правилам.

## 0. Общие принципы
- **Роли:** учитель (владелец аккаунта, ведёт учеников), ученик (приглашается учителем). Роль определяется аккаунтом, выбора роли при входе нет.
- **Дизайн:** стиль Apple — фон #F2F2F7/#F5F5F7, белые карточки, скругления 12–24 px, мягкие тени, системный шрифт (-apple-system, SF Pro), акцент #0A84FF, зелёный #34C759, оранжевый #FF9500, фиолетовый #A55CF5. Логотип — градиентный квадрат (#FF6B9A → #A55CF5 → #3D8BFF) с белым «V»-эквалайзером из 5 полосок.
- **Шапка** во всех разделах: логотип VibeOn слева, справа язык RU/EN и профиль; закреплена при прокрутке, полупрозрачная с размытием.
- **Левое меню** закреплено, при узком окне сворачивается в иконки.
- **Адаптивность:** три режима — широкий, компактный (≤1200 px: меню иконками, сетки по 2), телефон (≤760 px: одна колонка). Ничто не выходит за экран.
- **Подсказки** — единый стиль: мелкий серый курсив или свёрнутый блок «ⓘ Как это работает»; подписи к значкам — при наведении.
- **Языки:** RU и EN; выбор запоминается в профиле.

## 1. Вход и регистрация (4_экраны_входа)
- **Единый вход** для учителя и ученика: почта + пароль, «Запомнить меня» (включено), «Забыли пароль?», «Войти по ссылке на почту — без пароля», Яндекс ID и VK ID.
- **Регистрация учителя:** имя, почта, пароль, согласие на обработку ПД (152-ФЗ) → письмо с кнопкой подтверждения → кабинет. Пароль по почте не отправляется.
- **Ученик** регистрируется только по ссылке-приглашению учителя → экран «Анна, вас ждёт преподаватель» → стартовая анкета ученика (есть в прототипе ученика) → кабинет.
- После входа — сразу нужный кабинет по роли. Экран загрузки с анимированным логотипом показывается, только если загрузка дольше ~0,5 с.

## 2. Кабинет учителя (teacher-workspace.html)
### 2.1 Обновления
Приветствие, часы; «Сегодня» — уроки дня (время, ученик, статус домашки, «Открыть класс», комментарий к уроку с подсказкой полного текста при наведении, «Без комментария»); неделя по дням; «Что нового» — события с действиями («Ответить», «Проверить скриншот», «Решить»); галочка «сделано» ставится автоматически только при выполненном действии.
### 2.2 Расписание
Неделя в стиле Apple Calendar; урок — имя ученика + точка статуса; заметка к будущему уроку пишется в окне урока и видна в «Сегодня». Новый урок по клику на свободное время: выбор ученика с поиском (если >5), «Пробный урок», повтор по умолчанию выключен. «Итого за неделю» → Финансы.
### 2.3 Ученики
Вкладки: Анкеты · Маршруты · Оплаты · Фидбэк. «Пригласить ученика» (имя + почта/Telegram) → сразу «Поставить пробный урок». Архив анкет.
Анкета ученика — вкладки Анкета · Прогресс · Маршрут к цели · Фидбэк · История:
- **Оплата:** абонемент или постоплата, цены абонементов, «Выставлять счёт другому лицу» (родителю: кто, Telegram, почта); когда выставлять счёт (абонемент: осталось 1 / 2 урока / закончился; постоплата: после урока через 5/15/30/60 мин или на следующий день, раз в 4 недели от первого урока, вручную); напоминание при неоплате каждые 1/3/7 дней.
- **Маршрут к цели:** данные (входной тест/срезы, курсы и ведущий курс, срок — по умолчанию выключен, тип маршрута, цель A1+…C2, темп, «как занимается», заметки с диктовкой) → черновик ИИ (этапы CEFR, прогноз, критерии достижения) → «Утвердить» → ученик видит маршрут с картой.
- **История:** уроки (дата, время, статус, юнит, «Открыть») и оплаты/счета.
### 2.4 Чат, Домашка, Вопросы
- Чат — переписка с учениками; запрос чека → «Прикрепить чек».
- Домашка — карточки: На проверку / Не сделано / Проверено / Нет домашки; «Проверить» открывает урок на вкладке домашки.
- Вопросы — Новые / Отвеченные / Спрашивали ИИ; черновик ответа ИИ, «Написать свой».
### 2.5 Курсы
Разделы (общие → грамматика → лексика → международные экзамены → ЕГЭ/ОГЭ → разговорные → бизнес → дети), перетаскивание разделов, курсов, юнитов и уроков (порядок юнитов = точки маршрута). «Новый курс» — крупная карточка первой. Страница курса: шапка с обложкой, юниты лентой, уроки с номерами, «Конструктор», «Назначить».
### 2.6 Финансы
Обновления (Заработано — главная плитка, Получено, Ждём, Предоплачено, Отмены, Переносы), Доходы (столбики по месяцам), Ученики (полоски, таблица с номерами), Проверить постоплаты: вкладки «Ожидаем / Нужно проверить / Принято автоматически»; строка: ученик, подтверждение (скриншот + расшифровка ИИ, текст или «ничего не прислал» + «Выставить счёт повторно»), сумма колонкой, действие; автоприём при совпадении суммы; строки закрываются только вручную («ОК»), «Отменить» доступно.

## 3. Кабинет ученика (student-workspace.html)
- **Обновления:** следующий урок, домашка, заметки, мотивационный блок «всё сделано», лента событий.
- **Расписание:** название урока на всю ширину слота; перенос — в подсказке; свободное время → запрос доп. урока с готовым редактируемым сообщением.
- **Мои уроки:** курсы с переключателем, юниты и уроки.
- **Слова:** цель в стиле Duolingo (5/10/15/20 слов, дни, напоминание в Telegram с выбором времени), статистика (в списке, выучено, в тренировке, серия), тренировки.
- **Мой маршрут:** Обзор (цель, достижения за всё время с анимацией, карта-гора с анимацией и закраской пройденного, ракета-бустер, недельный отчёт, выбор темпа с меткой «учитель рекомендует»), С чего ты начал(а), Где ты сейчас (до ближайшей точки / до цели), Ближайшая точка, Финальная точка; блоки навыков раскрыты.
- **Прогресс:** изученные темы, динамика по месяцам (столбики по навыкам), фидбэк.
- **Вопросы и Сообщения:** с указанием курса · юнита · урока; уведомления.
- **Оплаты:** вкладки Тариф (абонемент: заморозить/продлить; постоплата: текущая цена + предложение абонемента) и Счета и оплаты (счёт с периодом, «Я оплатил(а)», «Мне нужен чек» → чат, история с «Твой чек»).

## 4. Страница урока / класс (platform-prototype.html)
- **Шапка:** плитка логотипа над левой колонкой; урок (курс · юнит · урок + название); вкладки Урок · Домашка · Новые слова (у ученика «Мои слова») · Доска; справа «О занятии» (учитель), язык, выход (учитель → кабинет учителя, ученик → кабинет ученика).
- **Сетка:** левая колонка (Чат, Словарь, Таймер) · задания · правая колонка (Присоединиться к звонку + присутствие, обложка, секции, заметки, кнопки учителя: Комментарий к ДЗ, Фидбэк ученику, Завершить урок). Ниже 980 px правая колонка уходит под задания.
- **Задание:** номер + формулировка в строке; содержимое начинается от первого слова формулировки. У учителя значки: показать ученику, в домашку, скрыть, «⋯» (изменить, проверка сразу/кнопкой, скрывать/показывать ответ). Учитель при наведении видит правильный ответ (пропуск — плашка справа, вариант — подсветка). «+» между заданиями и над первым — добавить задание на уроке.
- **Ученик:** «Мне непонятно» → поле «Опиши, что непонятно», сначала отвечает ИИ по правилам урока, затем можно спросить учителя. Форматирование текста (жирный, курсив, подчёркивание, крупнее/мельче, маркер, цвета).
- **Проверка:** сразу (до 3 попыток) или кнопкой «Проверить» (только у ученика, справа). После проверки верные ответы зелёным (в парах — уходят вниз в зелёный список), неверные красным, подпись «Ошибки помогают учиться» и кнопка «Сбросить ошибки и попробовать снова». Все кнопки действий ученика — по правому краю; задания разделены линией.
- **Форматы:** пары (сразу/кнопкой, цветные связи), тест A/B/C, «найди и исправь» в два шага, диктант (точно / орфография — оранжевым / не совпало), порядок перетаскиванием, эссе (исправление ИИ, форматирование учителем, «ОК, показать ученику», отметки в тексте ученика), разговор с ИИ (голос или текст, переслушать, скрипт), запись аудио (расшифровка → исправленная версия), аудио/видео со скриптом (учитель одной кнопкой открывает скрипт ученику).
- **Домашка:** вкладки учителя Все / Проверены автоматически / Требуют проверки. Во вкладке слов урока учитель кнопками «Тренировать новые слова» и «Общее повторение» назначает их в домашку — у ученика в домашке появляются карточки с кнопкой «Начать»; без назначения ученик может тренироваться сам, но в домашку это не попадает.
- **Доска:** над холстом единая панель: «Шаблоны» (интеллект-карта, за/против, линия времени, таблица), 6 основных цветов + «Другие цвета» (12 цветов и палитра), настройки выбранного инструмента (толщина / размер ластика / прозрачность маркера / заливка фигур / цвет стикера / цвет и плотность шторки), справа отменить, очистить, лазерная указка, следовать за мной, запретить рисование, загрузить фото/PDF. Слева от холста инструменты: Двигать (перемещение, растягивание за угол любого элемента, двойной клик — правка текста, Delete — удалить), ручка, маркер, ластик, линия, стрелка, прямоугольник, круг, текст, стикер, шторка (у ученика непрозрачная, у учителя — с выбранной плотностью, знак «?»). Шаблоны — редактируемые объекты на текущей странице: интеллект-карта из блоков-прямоугольников со связями (за центр двигается вся карта, «+ Ветка»), линия времени (отметки перетаскиваются, двойной клик по линии — новая точка, зоны между отметками подсвечены), таблица (+/− столбец и строка, двойной клик по ячейке, строки сами растут под текст). Страницы — номерами внизу.
- **О занятии:** ученик, учебник, урок, уровень → цель, время; автоперевод и подсказки ИИ; «Открыть анкету».

## 5. Конструктор урока (lesson-builder.html)
- **Шапка:** логотип (→ кабинет учителя), «Курс · Юнит · Урок» + название, Импорт, Учебник, Вид ученика, язык, Поделиться (ссылка без регистрации, PDF для печати с ключами), Начать урок (назначить / открыть класс).
- **Три зоны:** слева Урок/Домашка/Новые слова; центр — задания секции; справа секции, рубрики урока (Lead-in, Warm-up, Vocabulary…) с подсказками ИИ и идеями заданий, «После урока ученик сможет». Навигация по секциям внизу (← · список + «+» · →).
- **Единый шаблон задания:** значок и тип → формулировка (готовые + «Своя формулировка») → содержание (внутри поля «Из файла» с распознаванием и «Помочь с ИИ») → «Как оформить это задание» (свёрнуто) → Опции значками (скрыть, нумерация, не показывать ответ, скрипт, лимит, предпроверка ИИ, проверка учителем…) → прочие опции (ученик вписывает/перетаскивает, проверка сразу/кнопкой и т. д.). Превью «Ученик увидит» рядом, включая кнопку «Проверить».
- **Выделение текста в поле:** [ ] (пропуск), ✓ (верный вариант — только где есть варианты), «1.» (нумерация строк).
- **Каталог материалов:** Картинка, Текст, Аудио, Видео, Слова, Заметка, Ссылка; задания объединены по группам; «Заполни пропуски» объединяет ввод и перетаскивание.
- **Особенности:** картинки серией, обрезка, подписи, карусель/друг под другом; видео/аудио по любой ссылке (YouTube, VK Видео, Rutube, Google/Яндекс Диск…) или файлом; текст с картинкой и форматированием учеником; набор слов и «Новые слова» (поле + Надиктовать + Из файла + «Помочь с ИИ» дописывает в поле, «Добавить» создаёт карточки; пример со словом жирным + строка для своего примера ученика); «Собери предложение» — отдельные слова / служебное + основное, склейка через «_»; «Слово из букв» с таймером; кроссворд из словаря урока с выбором направления; трансформации и перевод — ИИ проверяет альтернативы; эссе/открытый ответ — поле для письма; запись аудио — широкая кнопка «Записать ответ», расшифровка по кнопке «Посмотреть расшифровку», внутри — исправленная версия; говорение — ИИ-собеседник: ситуация и роль, лексика (+ слова урока), грамматика (+ темы урока), цель общения (своя или из вариантов: соглашаться / не соглашаться с собеседником, объяснять причины, уточняющие вопросы, советы, убеждать, договориться о плане, поддерживать разговор), длительность; у ученика кнопки «Начать разговор» / «Ответить».
- **Импорт:** из файла (Word/PDF/фото) и из учебника (несколько файлов с ролями: Student’s Book, Workbook, Teacher’s Book, аудио; ИИ раскладывает по урокам; проверка урока за уроком).
