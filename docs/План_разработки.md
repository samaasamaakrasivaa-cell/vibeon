# План разработки VibeOn (по этапам)

1. **Основа:** проект Next.js + TypeScript, Docker, PostgreSQL + Prisma, дизайн-система (цвета, шрифты, кнопки, карточки, поля, сегменты, подсказки) по прототипам, шапка и левое меню, RU/EN.
2. **Вход:** регистрация учителя, подтверждение почты, вход паролем и по ссылке, Яндекс ID / VK ID, приглашение ученика и стартовая анкета, перенаправление по роли.
3. **Кабинет учителя — ученики и расписание:** анкеты, архив, расписание, уроки, пробный урок, заметки к урокам, «Сегодня».
4. **Курсы и конструктор:** курсы/юниты/уроки с перетаскиванием, конструктор с единым шаблоном заданий, превью, все типы заданий, импорт из файла, «Поделиться»/PDF.
5. **Урок (класс):** реальное время, показ ученику, проверка, домашка, доска, слова урока, звонок (ссылка), «О занятии», завершение урока.
6. **Кабинет ученика:** обновления, расписание, мои уроки, слова и тренировки, вопросы, сообщения.
7. **Оплаты:** абонементы и постоплата, счета по правилам, напоминания, скриншоты с распознаванием, автоприём, чеки, финансы учителя.
8. **ИИ:** шлюз, «Помочь с ИИ», распознавание учебника, проверка эссе, «Мне непонятно», ИИ-собеседник, речь.
9. **Маршрут:** входной тест, срезы, черновик маршрута ИИ, карта-гора, прогноз, недельный отчёт.
10. **Уведомления:** Telegram-бот и почта.
11. **Запуск:** домен, HTTPS, бэкапы, политика конфиденциальности, уведомление РКН, тарифы и оплата подписки, тестирование на телефоне.
