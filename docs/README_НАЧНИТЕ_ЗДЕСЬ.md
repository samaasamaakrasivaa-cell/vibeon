# VibeOn — документация проекта

VibeOn — действующая бета платформы для преподавателей английского и их учеников. Начните с документа, который соответствует вашей задаче.

| Если нужно | Где читать |
|---|---|
| Взять задачу в Codex | [AGENTS.md](../AGENTS.md) и [запуск команды Codex](CODEX_TEAM.md) |
| Понять текущую систему | [Архитектура и стек](Архитектура_и_стек.md) |
| Определить ответственного и смежные сценарии | [Карта модулей](MODULES.md) |
| Подготовить ветку, проверку или PR | [Правила разработки](DEVELOPMENT_RULES.md) |
| Подготовить выпуск либо восстановление | [Процедура выпуска](RELEASE_RUNBOOK.md) |
| Найти открытое продуктовое решение | [Реестр решений](PRODUCT_DECISIONS.md) |
| Запустить локальную разработку | [README репозитория](../README.md) |

## Предметные материалы

- [ТЗ](ТЗ_полное.md), [первоначальный план](План_разработки.md) и [прототипы](prototypes/) описывают исходные требования и дизайн. Данные в прототипах демонстрационные. Их ролевые переключатели служат для просмотра экранов.
- [Разметка заданий](Разметка_заданий.md) описывает формат материалов конструктора.
- [Документы по ИИ](ai/) и [промпты](../prompts/README.md) содержат предметные правила работы с моделями.
- [Первоначальные решения по запуску](Решения_и_доступы.md) содержат контекст выбора сервисов. Имена параметров окружения перечислены в [.env.example](../.env.example). Действующие настройки подтверждает ответственный за среду.
