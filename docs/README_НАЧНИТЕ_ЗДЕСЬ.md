# VibeOn — полный пакет материалов платформы

VibeOn — онлайн-платформа для репетиторов английского языка: кабинет учителя, кабинет ученика, онлайн-урок (класс) и конструктор уроков с ИИ.
Пакет собран 1 ноября 2026 года и содержит всё, чтобы любой разработчик или ИИ-ассистент (Claude Code, Cursor и т. п.) мог собрать настоящую платформу.

## Порядок чтения
1. **README_НАЧНИТЕ_ЗДЕСЬ.md** — этот файл.
2. **ТЗ_полное.md** — что должна уметь платформа: все разделы, экраны, правила и решения.
3. **Архитектура_и_стек.md** — как строить: стек, модель данных, ИИ, вход, оплаты, уведомления, юридические требования.
4. **Разметка_заданий.md** — формат содержания заданий конструктора (скобки, звёздочки и т. д.).
5. **План_разработки.md** — по каким этапам собирать.
6. **Решения_и_доступы.md** и **.env.example** — домен, сервер, почта, ИИ, ключи сервисов, тарифы, видеозвонок: что выбрано, где получить, куда вписать. Для разработки ничего из этого не нужно — работаем с заглушками.
6. **1_прототипы/** — эталон внешнего вида и поведения. Открывайте файлы в браузере. Начните с **1_прототипы/вход_и_регистрация/index.html** — это стартовая страница сайта.
7. **3_скриншоты/** — все экраны картинками (на случай, если ИИ не может открыть HTML).

## Что внутри
| Папка | Содержимое |
|---|---|
| 1_прототипы | 4 рабочих HTML-прототипа + папка «вход_и_регистрация» (стартовая страница сайта: index.html — вход, регистрация учителя, «Проверьте почту», приглашение ученика, загрузка) |
| 2_исходный_код | JavaScript каждого прототипа отдельно + build.py для сборки JS обратно в HTML |
| 3_скриншоты | 38 скриншотов всех ключевых экранов |
| 4_экраны_входа | Экраны входа и регистрации: исходники (.dc.html) и папка «просмотр» с обычными HTML |
| 5_история | Полная история обсуждения с Claude (все решения и причины) |

## Важно понимать про прототипы
- Это **эталон дизайна и логики**, а не готовый код продукта. Данные — демонстрационные и живут внутри файла; после перезагрузки сбрасываются.
- Каждый прототип — отдельный файл. Связи между ними сделаны ссылками; общей базы данных нет. В настоящей платформе всё работает на одной базе.
- Переключатели «Учитель / Ученик» (T/S) и «Как видит ученик» — только для демонстрации. В продукте роль определяется аккаунтом.
- ИИ-функции в прототипах — заготовки или вызовы внутри claude.ai. В продукте — через серверный ИИ-шлюз (см. Архитектура).

## Готовая инструкция для ИИ-разработчика
Скопируйте в начало работы:

> Ты собираешь веб-платформу VibeOn для репетиторов английского. В этой папке: ТЗ (ТЗ_полное.md), архитектура (Архитектура_и_стек.md), формат заданий (Разметка_заданий.md), план (План_разработки.md) и HTML-прототипы — эталон дизайна и поведения (1_прототипы, скриншоты в 3_скриншоты). Стек: Next.js + TypeScript, PostgreSQL, Prisma, Docker, сервер TimeWeb (Москва). Повторяй дизайн прототипов максимально точно (стиль Apple: белые карточки, системный шрифт, синий акцент #0A84FF, скругления 12–24 px). Работай по этапам из План_разработки.md, после каждого этапа показывай результат. Доступов к домену, серверу и сервисам пока нет: разрабатывай локально с заглушками, как описано в Решения_и_доступы.md (раздел 7), настройки бери из .env.example.
