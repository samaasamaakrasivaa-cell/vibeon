# Формат содержания заданий (разметка конструктора)

Содержание задания — обычный текст с простой разметкой. Строки — элементы задания. Нумерация в начале строк («1.», «a)») при разборе отбрасывается.

| Тип | Разметка | Пример |
|---|---|---|
| Заполни пропуски (вписать / перетащить) | ответ в [ ]; подсказка в ( ) после; варианты через / | `Yesterday I [went](go) to the cinema.` · `[colour / color]` |
| Выбрать из списка | все варианты в [ ] через /, верный с * | `It’s fine to [make* / do / take] mistakes.` |
| Тест | вопрос, ниже варианты по строке, верный с *, между вопросами пустая строка | `What does “give it a go” mean?`↵`to leave`↵`to try*` |
| Верно / неверно | утверждение — T / F / NS | `Perfectionism can stop people — T` |
| Соедини пары | левое — правое | `outcome — the result` |
| Распредели по колонкам | Колонка: слово, слово | `Nouns: cat, house` |
| Слово к картинке | слово на строку (+ картинка к каждому) | `cat` |
| Собери предложение | правильное предложение на строку; склейка слов через _ | `I want to look_after my brother.` |
| Порядок текста | строки в правильном порядке | — |
| Слово из букв | слово — подсказка | `patient — able to wait calmly` |
| Найди и исправь ошибку | [неверно / верно*] | `She [don’t / doesn’t*] like coffee.` |
| Трансформация | предложение \| КЛЮЧЕВОЕ СЛОВО → ответ | `I started two years ago. \| BEEN → I have been…` |
| Перевод | русское → английское | `Стоит попробовать. → It’s worth a try.` |
| Кроссворд | слово — подсказка | `goal — what you want to achieve` |
| Говорение | вопрос на строку | — |
| Диктант | предложение на строку (озвучивается) | — |
| Набор слов | слово — перевод/определение — пример (любой формат, «Помочь с ИИ» приводит к нему) | `outcome — результат — We can’t control the outcome.` |

Опции задания (JSON): hidden, nonum, noreveal (не показывать ответ после 3 попыток), checkMode (instant|button), mode (gap|drag; drag|type для картинок), split (word|chunk), limit/limitSec/limitMin, showScript, sync, stuFmt, pic/picSrc, caps, stack, voice, aiEx, wmode (tr|def), multi, ns, fix, check (проверка учителем), aipre (предпроверка ИИ), ai (ИИ-собеседник) + aiPrompt/aiWords/aiGoal/aiMins, tracks, src, script.
