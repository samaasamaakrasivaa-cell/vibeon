# CD-01: завершение автоматической выкладки

Владелец поручил доводить обычные согласованные задачи до проверенного результата на сайте без повторного разрешения на merge или публикацию. Выполнение поручено существующим GitHub Actions и серверному подключению; установка Codex на MacBook не является условием работы серверной выкладки. Новые ключи API и платные сервисы не добавляются.

## Первый этап: фактический доступ

`Delivery preflight` проверяет уже существующее подключение `SSH_KEY` / `SSH_HOST`. После интеграции проверенного PR в `main` workflow запускается автоматически. Для PR выполняются только синтетические проверки самого скрипта; доступа к серверу у этого этапа нет. На сервере скрипт только читает разрешённые метаданные, не запускает выпуск и не меняет приложение, БД или файлы.

Результат — обезличенная сводка о текущем образе, количестве контейнеров, ожидаемой топологии и доступности приложения. Полная конфигурация, журналы сервера, секреты и данные пользователей не публикуются. Неизвестная топология или отсутствие технического доступа возвращают конкретный неуспешный результат, а не статус «готово к выкладке».

## Следующий этап: исполнитель выпуска

После проверки фактической топологии отдельный job существующего CI должен выполнять выпуск только принятого коммита `main`, после успешных зависимых проверок и повторной сверки актуального SHA. Для серверных операций используется общая группа `server`, совместимая с существующим workflow `Server`.

Перед автоматическим переключением должны быть реализованы и проверены:

- передача того же неизменяемого образа, который проверен CI;
- сохранение совместимого образа отката;
- согласованная и проверенная копия БД и загрузок на сервере;
- остановка при ошибке копирования, неизвестном писателе или непроверенной миграции;
- проверка полного SHA и поведения приложения после переключения;
- возврат к совместимому образу с текущими томами при неуспешном запуске, без автоматической замены новых ответов старой БД.

Первый выпуск сохраняет согласованный порядок: TE-02/TE-03 на `01da92f1332056aaacc01ec6a6731f72e1bb45e0`, затем PT-01 с заранее сохранённым совместимым образом `c2996ff7ffb670449de1886738791cb18c279fab`. Текущая `main` уже включает PT-01; её нельзя незаметно выдать за отдельный выпуск TE.

Автоматическое обновление сайта пока не включено. Этот документ фиксирует реализуемый этап, а не подтверждение публикации. Технические проверки выполняют агенты и workflow; повторное продуктовое согласие владельца для обычного выпуска не требуется. Реальные ограничения доступа сохраняются.
