# PT-10. Объективные факты для предложения уровня

[Контракт №36](https://github.com/samaasamaakrasivaa-cell/vibeon/issues/36#issuecomment-7240924271)

Сборщик принимает сохранённое состояние попытки. При подключении вызывающий код проверяет, что попытка сдана и принадлежит назначенному преподавателю.

- Грамматика и лексика используют записи из `state.core`, снимки заданий и сохранённые `answers.ok`. Завершённый основной блок даёт счёт и, если сохранена, вычисленную при прохождении ступень. Факты по темам детализируют тот же блок. Их нельзя суммировать со счётом блока. Уровень из `state.base` сам по себе не подтверждает грамматику.
- Чтение и аудирование используют только завершённые тексты из `rdone` и `ldone` и сохранённые оценки всех их вопросов. Ступень вычисляется по действующему правилу Placement отдельно для исходной группы и каждого надёжно выделенного дополнительного текста.
- Дополнительные задания ядра опознаются по `z` и `vz`. Эти метки подтверждают происхождение вопроса, но не связывают его с конкретным раундом. Поэтому дополнительный вопрос остаётся отдельным фактом. Дополнительный текст при каждом назначении добавляется в конец списка. Его можно связать с записью `xs`, если совпадают порядок, количество, уровень задания и сохранённая история. Активный повтор не входит в подтверждённые данные.
- Для раздела из `addSections` можно доказать происхождение, если он есть в списке разделов и завершён строго после последнего добавления, а повтор не заменил дату завершения. Когда история неоднозначна, сборщик возвращает `unknown-origin`. `not-tested` означает отсутствие прохождения, `not-confirmed` — незавершённый исходный блок или повтор. У пробела нет балла и уровня.

Результат содержит факты с условными ID, отдельно соответствующие им серверные ссылки на сохранённые задания и метку версии. Метка меняется при замене доказательства или ответа, даже если балл тот же. В фактах и ссылках на доказательства нет текста ответа, задания или расшифровки. Вызов модели, Writing/Speaking, зачёт №40 и подтверждение итогового уровня подключаются отдельно.

## Фикстуры

```sh
node --conditions=react-server --import tsx scripts/check-placement-objective-facts.ts
```
