# PT-12. Запись подтверждённого результата для Roadmap

[Решение в №37](https://github.com/samaasamaakrasivaa-cell/vibeon/issues/37#issuecomment-7240105154) · [Формат читателя №105](https://github.com/samaasamaakrasivaa-cell/vibeon/blob/1f193a5cac39875917e3794a4e522c1d2c63dd89/docs/placement/PT-05-roadmap-proposal.md#вход-placement)

Внутренний [модуль записи](../../src/lib/placement/roadmap-result.ts) готовит команду по проверенным на сервере фактам. Только владелец назначенной попытки в статусе `submitted` или `reviewed` может сохранить полный снимок в `review.roadmapResultV1`. При записи сервер заново получает факты и сверяет текущую версию ответов и предыдущую версию результата. Повтор команды возвращает уже сохранённый снимок и время. При конкурентной правке сервер перечитывает запись. Устаревшая команда не записывается.

Writing и Speaking получают уровень по Cambridge-рубрике только для действующего подтверждения преподавателя, привязанного к актуальному ответу. Для Speaking вызывающий серверный код дополнительно проверяет происхождение каждого использованного аудио и передаёт отпечаток этой версии. Снимок допускает только перечисленные в контракте поля. Черновики ИИ, расшифровки и тексты ответов в снимок не копируются. Отсутствующая запись, неподтверждённый результат и неизвестный источник представлены отдельными причинами.

Для разделов из `addSections` используется сохранённый список разделов и дата завершения каждого навыка. `additional` возможен, когда раздел входит в этот список и завершён строго после последнего добавления. Дата до добавления, совпадающая дата или отсутствие даты дают `unknown-origin`: попытка хранит время только последнего добавления. Отдельное назначение другого уровня подтверждается признаком `wsExtra` для самого навыка.

Под флагом `PL_ROADMAP_CONFIRM=1` назначенный преподаватель видит проверенные факты, пробелы и подсказку по действующей медиане Placement. Подсказка берёт по одной ступени на навык, предпочитая первый доступный факт, и не подставляет итог. Преподаватель выбирает уровень и факты явно. Сервер извлекает преподавателя из сессии и проверяет версию сдачи, факты и предыдущую версию снимка перед записью. Отдельное действие утверждения пишет только `review.roadmapResultV1`. Формирование и отправка отчёта, окончание повторного раздела и очередь проверки живут отдельно. Флаг выключен по умолчанию.

При загрузке Speaking по штатному пути тот же атомарный переход сохраняет в попытке связку «попытка, задание, вопрос, ссылка на версию и SHA-256 файла». Перед передачей Speaking сервер читает текущие файлы и сверяет все поля и содержимое. Запись старого формата, чужая привязка, пропавший или заменённый файл дают `unknown-origin`. Для частичного Speaking проверяются все имеющиеся аудио. В Roadmap и HTML страницы служебные ключи и хеши аудио не передаются. Изменение JSON не требует миграции.

## Воспроизведение

Применить текущие миграции на отдельной PostgreSQL 16 с БД `pt_roadmap_writer_fixture` по адресу `127.0.0.1`. Скрипт отклоняет другой адрес или имя БД.

```sh
node --conditions=react-server --import tsx scripts/check-placement-roadmap-result.ts
```

Для проверки совместимости можно указать `ROADMAP_CONTRACT_MODULE` с абсолютным путём к `src/lib/roadmap/placement-proposal.ts` из отдельной копии на SHA читателя `1f193a5cac39875917e3794a4e522c1d2c63dd89`. В тесте серверные подтверждения и подтверждение уровня заданы синтетическими данными. Используется настоящая запись с повторным чтением PostgreSQL. Проверяется первая запись, два одновременных повтора, сохранность времени, отказ после замены аудио или уровня, сохранность отчёта и его параллельного черновика, маршрута, ученика, прогресса и Checkpoint.

Для сквозной проверки запустите локальное приложение на `127.0.0.1:3089` с `PL_ROADMAP_CONFIRM=1`, `PL_WS_TEACHER_WRITE=1`, той же синтетической БД и новым `UPLOAD_DIR`, созданным командой `mktemp -d /tmp/vibeon-pt36-synthetic-XXXXXX`. Отключите SMTP и Telegram. Скрипт принимает только этот локальный адрес и указанную тестовую БД.

```sh
PT_LEVEL_FIXTURE_ORIGIN=http://127.0.0.1:3089   PL_ROADMAP_CONFIRM=1 PL_WS_TEACHER_WRITE=1   node --conditions=react-server --import tsx scripts/check-placement-level-confirmation.ts
```

Для запуска из браузера укажите абсолютный путь к модулю Playwright в `PT_LEVEL_BROWSER_MODULE` и при необходимости путь к Chromium в `PT_LEVEL_BROWSER`. Для проверки штатного чтения укажите абсолютный путь к `src/lib/roadmap/placement-proposal-data.ts` из отдельной копии PR №105 на `b7da4ce451337dd637ca76bc54e986b3f73291e0` в `PT_LEVEL_ROADMAP_READER`. Скрипт загружает синтетический WAV через обычный HTTP, проверяет несоответствие задания, попытки, вопроса и файла, запускает явное подтверждение, повтор и отказ устаревшей команды. Затем сверяет прежний отчёт, маршрут, прогресс и Checkpoint.
