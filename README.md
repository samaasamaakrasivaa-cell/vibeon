# VibeOn

Платформа для репетиторов английского: кабинет учителя, кабинет ученика, онлайн-урок и конструктор уроков.

**Стек:** Next.js 15 (App Router) + TypeScript · PostgreSQL 16 + Prisma 6 · Redis · Tailwind CSS 4 · Docker Compose · Nginx.

## Запуск на компьютере (разработка)

Нужно: Node.js 22, Docker.

```bash
cp .env.example .env              # заполнить AUTH_SECRET
docker compose -f docker-compose.dev.yml up -d   # база, Redis, Mailpit
npm install
npx prisma migrate dev            # создать таблицы
npm run db:seed                   # демо-учитель и демо-ученик
npm run dev                       # http://localhost:3000
```

Страницы: `/login` — вход, `/signup` — регистрация учителя, `/teacher` — кабинет учителя, `/student` — кабинет ученика,
`/ui` — дизайн-система, `/api/health` — проверка сервера и базы.

Демо-аккаунты (после `npm run db:seed`): `teacher@demo.vibeon` и `student@demo.vibeon`, пароль `demo12345`.

Письма: если `SMTP_HOST` пустой, письма не отправляются, а пишутся в лог сервера и видны на странице `/dev/mail`
(только в режиме разработки). С Mailpit (`docker-compose.dev.yml`) — `SMTP_HOST=localhost`, `SMTP_PORT=1025`, письма на http://localhost:8025.

## Вход и регистрация (этап 2)

- Учитель: `/signup` → письмо «Подтвердите почту» → кабинет. Без подтверждения вход не пускает и присылает письмо снова.
- Вход: пароль («Запомнить меня» — 30 дней), ссылка на почту без пароля (15 минут), «Забыли пароль?» (ссылка на 1 час, одноразовая; после смены пароля выходим на всех устройствах).
- Яндекс ID и VK ID включаются сами, когда в `.env` заданы `YANDEX_CLIENT_ID/SECRET` и `VK_CLIENT_ID/SECRET`.
  Адреса возврата: `https://ДОМЕН/api/auth/callback/yandex` и `https://ДОМЕН/api/auth/callback/vk`.
- Ученик: учитель в разделе «Ученики» вводит имя и почту или Telegram → ссылка-приглашение на 14 дней →
  «Анна, вас ждёт преподаватель» → стартовая анкета → шаг «Подключите Telegram» → кабинет ученика. Учитель получает уведомление.
- Роли: учитель не видит кабинет ученика и наоборот; без входа кабинеты закрыты.
- Защита: пароли — bcrypt, сессии — httpOnly-кука, токены в базе только в виде хэша, ограничение частоты попыток входа и регистрации.

## Запуск на сервере (TimeWeb VPS, Ubuntu 24.04)

```bash
# 1. Один раз: установить Docker
curl -fsSL https://get.docker.com | sh

# 2. Забрать код
git clone https://github.com/<владелец>/vibeon.git && cd vibeon

# 3. Настройки
cp .env.example .env && nano .env   # NODE_ENV=production, APP_URL, AUTH_SECRET, POSTGRES_PASSWORD

# 4. Запуск (миграции базы применяются автоматически)
docker compose up -d --build
```

Обновление: `git pull && docker compose up -d --build`.
HTTPS (Let's Encrypt), бэкапы базы и автодеплой из GitHub настраиваются на этапе 11.

## Кабинет учителя (этап 3)

- **Расписание** (`/teacher/schedule`): неделя по поясу учителя, линия текущего времени, цвет по статусу.
  Клик по свободному времени — новый урок (поиск ученика, пробный урок по имени, 45/60/90/120 мин, повтор каждую неделю).
  Окно урока: заметка (видна в «Сегодня»), «Сделать повторяющимся», «Что произошло?» (проведён / пропуск со списанием или без / отменён),
  перенос только этого урока, удаление одного или «этот и все следующие». Внизу — заработано по дням и «Итого за неделю».
  Еженедельные уроки создаются на полгода вперёд и продлеваются сами; прошедшие отмечаются как проведённые.
- **Ученики** (`/teacher/students`): карточки с поиском, вкладки «Анкеты · Маршруты · Оплаты · Фидбэк», архив,
  «Пригласить ученика» → «Поставить пробный урок».
- **Анкета** (`/teacher/students/[id]`): контакты, «О себе», ответы стартовой анкеты, личные заметки (сохраняются сами),
  оплата (абонемент/постоплата, когда выставлять счёт, напоминания, цены абонементов, плательщик), абонемент с кольцом,
  следующий урок, «Вместе», вкладка «История» (уроки и счета), архив и удаление.
- **Обновления** (`/teacher`): «Сегодня» (время, ученик, домашка, класс, комментарий), неделя по дням, «Что нового» с отметкой «сделано».

## Курсы и конструктор (этап 4)

- **Курсы** (`/teacher/courses`): разделы (общий, грамматика, лексика, экзамены, ЕГЭ/ОГЭ, разговорный, бизнес, дети),
  перетаскивание разделов и курсов, «Новый курс».
- **Курс** (`/teacher/courses/[id]`): обложка (загрузка картинки), юниты и уроки с перетаскиванием (в том числе между юнитами),
  переименование на месте, объединение отмеченных уроков, «Конструктор», «Назначить» (на ближайшее занятие ученика).
- **Конструктор** (`/builder/[id]`): части «Урок / Домашка / Новые слова», рубрики (Lead-in, Vocabulary… + свои),
  подсказки по рубрикам, «После урока ученик сможет», вставка задания в любое место, скрыть / вверх / вниз / в домашку / удалить,
  «Вид ученика», «Поделиться» (гостевая ссылка, можно выключить или сменить), PDF для печати с ключами и без.
- **Окно задания**: готовые формулировки и своя, содержание с разметкой ([ ] пропуск, ✓ верный, 1. нумерация), «Как оформить»,
  опции (скрыть, без нумерации, не показывать ответ, проверка учителем, вписывает/перетаскивает, проверка сразу/кнопкой,
  серии, лимит слов, таймер…), живое превью «Ученик увидит» с кнопкой «Проверить».
- **Типы заданий** (`src/lib/tasks`, `src/components/tasks/TaskView.tsx`): картинки, видео (YouTube, Rutube, VK, файл), аудио, текст,
  набор слов, заметка, ссылка, разделитель, заполни пропуски (вписать/перетащить, серии), выбор из списка, тест, верно/неверно/не сказано,
  пары, колонки, слово к картинке, собери предложение, текст по порядку, слово из букв (таймер), сочинение, открытый ответ,
  запись аудио, говорение, найди и исправь ошибку, перефразирование, перевод, диктант (озвучка в браузере), кроссворд.
  Формат разметки — `docs/Разметка_заданий.md`.
- **Файлы**: `POST /api/upload` (до 50 МБ: картинки, аудио, видео, PDF), `GET /api/files/…` (с перемоткой). Хранятся в `./uploads`
  (в Docker — том `uploads`); S3 — на этапе 11.
- Требуют ИИ и появятся на этапе 8: импорт из файла и учебника, «Помочь с ИИ», «Прикрепить упражнение», ИИ-собеседник,
  расшифровка записи, проверка альтернативных ответов.

## Урок / класс (этап 5)

- **Адрес** `/class/[id]` (id занятия из расписания). Войти могут только учитель урока и его ученик.
  Кнопки «Открыть класс» — в «Сегодня», в окне урока в расписании и в анкете ученика.
- **Реальное время**: Server-Sent Events (`/api/class/[id]/events`) + действия (`POST /api/class/[id]/act`).
  Шина событий — в памяти процесса (одно приложение); запись доски, состояния урока и ответов идёт по очереди, без потерь.
  В Nginx для потока событий отключена буферизация.
- **Учитель**: переход по рубрикам (ученик следует), «Показать ученику» (подсветка задания), скрыть задание на этом уроке,
  отправить в домашку, «+» — добавить задание прямо на уроке, правильный ответ при наведении, «О занятии».
- **Ученик**: ответы сохраняются и сразу видны учителю, «Проверить» (только у ученика), «Мне непонятно» → вопрос учителю.
- **Домашка**: «Все / Проверены автоматически / Требуют проверки», проверка открытых ответов с комментарием («ОК, показать ученику»),
  карточки тренировки слов, комментарий к ДЗ.
- **Слова урока**: British/American озвучка, добавление слова, «Тренировать новые слова» и «Общее повторение» в домашку.
- **Доска**: ручка, маркер, ластик, линия, стрелка, прямоугольник, круг, текст, стикер, шторка; двигать и растягивать за угол,
  Delete — удалить, двойной клик — изменить текст; 6 цветов + палитра; толщина, заливка, плотность шторки; шаблоны
  (интеллект-карта, за/против, линия времени, таблица); страницы; отменить, очистить, лазерная указка, «Следовать за мной»,
  запретить рисование, загрузить фото.
- **Колонки**: чат, словарь (внешние словари + «в слова урока»), таймер (виден обоим); «Присоединиться к звонку»
  (ссылка из занятия, анкеты ученика или профиля учителя), присутствие, заметки учителя и ученика, фидбэк, «Завершить урок»
  (статус «проведён», домашка ученику, слова урока — в его список, уведомление).

## Кабинет ученика и общение (этап 6)

- **Ученик**: «Обновления» (следующий урок → «Войти в класс», «Заверши домашнее задание», заметки после урока с галочками,
  заметки преподавателя, слова на сегодня, «Что нового»); «Расписание» (неделя; клик по свободному времени — запрос доп. урока
  готовым сообщением; перенос урока); «Мои уроки» (курсы, юниты, статусы домашки); «Слова» (цель 5/10/15/20 в день, дни,
  время напоминания, статистика, серия дней, тренировка с интервальным повторением: карточка → выбор перевода → написать слово →
  на слух; «Общее повторение»; свои слова и примеры); «Вопросы»; «Сообщения»; «Прогресс» (темы, фидбэк); «Профиль» (данные, пароль).
- **Учитель**: «Домашка» (на проверку / не сделано / проверено / нет домашки → «Проверить» открывает класс на вкладке домашки),
  «Вопросы» (новые / отвеченные / спрашивали ИИ, ответ прямо в строке), «Чат» (переписка с каждым учеником, мгновенная доставка).
- Счётчики непрочитанного в меню у обоих.
- Экран загрузки с логотипом — клиентский (`NavLoader`), показывается при переходе дольше 0,5 с. Корневой `app/loading.tsx`
  убран: он оборачивал страницы в Suspense, и после серверных действий обновлённая страница иногда не применялась.

## Структура

```
prisma/schema.prisma   модель данных (все сущности из Архитектура_и_стек.md)
src/app/               страницы: teacher/*, student/*, ui, api/health
src/components/        шапка, меню, логотип, иконки, часы
src/lib/i18n/          переводы RU/EN (все строки — через ключи)
src/app/globals.css    дизайн-система: цвета, кнопки, карточки, поля, сегменты, адаптивность
docker-compose.yml     сервер: app + PostgreSQL + Redis + Nginx
docker-compose.dev.yml разработка: PostgreSQL + Redis + Mailpit
nginx/default.conf     прокси, WebSocket, лимит загрузки файлов
```

## Адаптивность
- Широкий экран: меню с подписями.
- ≤1200 px: меню иконками, подписи — при наведении, сетки по 2.
- ≤760 px (телефон): одна колонка, меню — горизонтальная лента под шапкой.
