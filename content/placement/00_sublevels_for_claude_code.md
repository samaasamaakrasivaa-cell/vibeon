# Подуровни во вводном тесте VibeOn — логика для платформы

Согласовано с методистом (заменяет первую версию документа: «минусовые» подуровни и взвешенное среднее убраны).

## 1. Шкала

9 ступеней — те же, что в Roadmap:

| Индекс | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| Подуровень | A1 | A1+ | A2 | A2+ | B1 | B1+ | B2 | B2+ | C1 |

Ниже A1 и выше C1 шкала не идёт.

## 2. Связь с полем band

- band 1 уровня X → ступень X;
- band 2 и band 3 уровня X → ступень X+ (для C1 — тоже C1: эти задания подтверждают C1).

## 3. Ядро (грамматика и лексика) — адаптивная «лесенка»

1. Старт с B1. Если ученик на вводном экране отметил «начинаю с нуля» — с A1.
2. Сначала шаги через целый уровень (B1 → B2 → C1 или B1 → A2 → A1), затем по одной ступени, чтобы уточнить подуровень.
3. По ходу: блок из 3 заданий одной ступени, грамматика и лексика вперемешку. 2 из 3 и больше — ступень пройдена, идём выше; меньше — ниже.
4. На границе (последняя пройденная ступень и первая непройденная) — по 5 заданий; ступень пройдена при 4 из 5.
5. Результат ядра — самая высокая пройденная ступень, при условии что ступень ниже тоже пройдена («перепрыгнул» — засчитывается нижняя).
6. Около 30–35 заданий в ядре. Задания не повторяются, внутри ступени выбираются случайно, по возможности с разными topic_id.

## 4. Чтение и аудирование

- Тексты и записи уровня результата ядра. Результат — % верных ответов по всем вопросам этого уровня.
- Если результат низкий, даётся запасной текст (запись) на уровень ниже.

## 5. Письмо и говорение

- Задание уровня результата ядра. Оценивает учитель вручную по 15_rubrics.json, подуровень по каждому критерию; платформа показывает подсказку (среднее, округлённое вниз).

## 6. Итог

- Взвешенного среднего нет. Учитель видит таблицу: % по навыкам и уровням, подуровни письма и говорения и простую подсказку системы.
- Итоговый подуровень выбирает учитель. Он становится точкой A маршрута.
- Ученик видит результат, только когда учитель включит «Показать результат ученику». Для внешней ссылки учитель заранее решает, показывать ли результат в конце.

## 7. Что сохранять

По каждому ответу: id задания, topic_id, level, band, ответ ученика, верно или нет, время ответа. По прохождению: путь по ступеням в ядре, результат каждого навыка, итоговый подуровень, кто и когда его подтвердил, а также снимок заданий, по которым отвечал ученик.
